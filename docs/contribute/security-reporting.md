Report security problems privately. Do not raise a public issue.

To report a problem, go to the repository concerned on GitHub. Select the **Security** tab, then **Report a vulnerability**. Each repository's SECURITY.md file gives the same instructions and names the contact.

Every repository has secret scanning, push protection, Dependabot alerts and a protected main branch. We scanned the full git history of each repository before making it public on 7 November 2026.

The [security answers](/reference/apps/install/security-answers) page explains what data the apps hold, where it is stored, how keys and secrets are managed and which sub-processors are involved. See also the [ISO/IEC 27001 Annex A statement](/reference/apps/install/iso27001-annex-a) and the [privacy notice](/reference/apps/install/privacy).
