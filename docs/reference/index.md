Facts to look up, not read through. Most of this section is held in the app repositories and pulled in when the site builds, so a change to an app changes its reference page in the same pull request. "Edit this page" on those pages opens the app's repository.

- **Apps**: each app's own docs/ folder: user guide, link set-up notes, runbook, schema notes
- **Exchange formats**: the seven versioned JSON Schemas (calibration set, board directions, register extract v2, findings, matter brief, confidentiality position, board view) with examples, from Triodian_Metamodel
- **Atlas API and MCP server**: endpoints, parameters, the keyless tier and its rate limit, registration for firms
- **Installer and scripts**: install.mjs, the provisioning script, close-client, the suite and chain tests

Generated per-app pages (steps or decisions, checks, roles, outputs, set-up fields, environment variables, status endpoint) are built from each app's content and roles files in task D.3.
