You install and run the apps. Each app is a Cloudflare Worker with a D1 database behind Cloudflare Access; the installer creates all of it from one command and no secret is typed. The deploying guides cover a fresh install, provisioning a client, rotating keys and tokens, and closing a client. The security page (after counsel's review) says what data is held and where.
